Backup & Restore Data

Unduh cadangan semua data (stok, faktur, tagihan, pembelian, pengeluaran, profil toko) sebagai file .json. Simpan file ini di tempat aman — kalau ganti laptop/HP atau buka file web ini di perangkat baru, tinggal restore dari file backup supaya data lama muncul kembali.

Perhatian: Restore akan menimpa semua data yang ada saat ini di web ini dengan data dari file backup. Butuh password.
